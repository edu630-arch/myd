# ✨ 오늘의 마음 일기 (AI Mind Diary)

Google Gemini 생성형 AI와 Firebase Firestore 데이터베이스를 연동한 감성 마음 일기 웹 애플리케이션입니다.

---

## 🌟 주요 기능
1. **🎙️ 실시간 한국어 음성 인식 (Web Speech API)**: 목소리로 말하면 일기 입력창에 자동으로 타이핑됩니다.
2. **✨ Google Gemini AI 감정 분석**: 일기의 내용을 깊이 분석하여 대표 감정(이모지, 감정명)과 맞춤형 따뜻한 위로/응원 메시지를 전달합니다.
3. **💾 Firebase Firestore 데이터베이스 연동**: 작성한 일기와 AI 분석 결과를 안전하게 실시간 저장하고 최근 일기 목록에서 다시 열어볼 수 있습니다.
4. **🎨 포근한 파스텔톤 반응형 UI**: PC와 모바일 모두에서 편안하게 사용할 수 있는 따뜻한 디자인입니다.

---

## 🚀 실행 방법
- 단일 `index.html` 파일로 구성되어 있어 브라우저에서 바로 열거나 GitHub Pages, Vercel(Static) 등에 올려 즉시 사용할 수 있습니다.
